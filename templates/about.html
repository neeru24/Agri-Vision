About Agri-Vision

AI-Powered Crop Disease Detection

Agri-Vision helps farmers and agronomists detect cotton crop diseases early using deep learning. Upload a leaf image and our ResNet50 + YOLOv8 ensemble returns a diagnosis, confidence score, and treatment guidance in seconds.

Smart Diagnosis

Combines ResNet50 classification with Grad-CAM explainability to highlight the regions driving each prediction.

Weather Aware

Integrates live weather data to provide irrigation and fertilizer recommendations tailored to field conditions.

Actionable Insights

Turns raw model output into severity grades, trend analytics, and plain-language treatment plans.

Built With

Python Flask PyTorch ResNet50 YOLOv8 OpenCV HTML / CSS / JS
